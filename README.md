# Team Task Board

A single-page task board built with Vite, React and TypeScript (strict). State uses only `useReducer` and Context.

## Install and run

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build
npm test         # run the Vitest tests
npm run lint
```

The mock API is slow (700 ms) and fails about 20% of the time on purpose. Use the Retry button when it fails.
